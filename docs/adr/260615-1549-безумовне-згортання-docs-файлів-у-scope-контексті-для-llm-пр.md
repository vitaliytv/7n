Функція `push` у `npm/push.js` у фолбек-режимі (без change-файлів) передає LLM повний перелік змінених файлів у вигляді `git diff --cached --name-status` для формування scope коміт-повідомлення. * Згортати `docs/`-файли лише за порогу >10 змінених файлів (початково реалізовано у сесії, потім відкинуто)
* Згортати `docs/`-файли завжди, незалежно від кількості файлів

Chosen option: "Згортати `docs/`-файли завжди, незалежно від кількості файлів", because поріг >10 ускладнює логіку без реальної вигоди — `docs/`-файли не несуть сенсу для коміт-меседжу навіть якщо їх один, і спрощена безумовна гілка легша в розумінні та тестуванні.
